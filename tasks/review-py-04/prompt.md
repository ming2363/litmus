# 审查冷箱电费结算改动

结算模块有一次改动。`patch.diff` 是这次改动，仓库里的其余文件是改动后的完整内容。请审查这次改动引入的缺陷，把意见写入工作目录根的 `review.json`。

`review.json` 是 JSON 数组。每条是一个对象，字段为 `file`、`line`、`category`、`description`。行号按改动后的文件计算。`file` 相对仓库根，使用正斜杠，不以 `./` 开头。`category` 只能是下面之一：空指针、越界、资源泄漏、并发、注入、逻辑错误、性能。

最多 10 条。命名、排版、注释和风格问题不写入。

## 如何自测

执行 `python3 litmus.py check`。它只检查 JSON 结构，不判断审查意见对不对。
