# 调度台说明

本文是 2026 年调度台的现行口径。`docs/archive/` 里保留的是 2023 年交接班备忘，程序已经不再按那套计算。

分钟编号从计划周周一 00:00 起算，可以是负数，类型是整数。勾选框留下来的布尔值不是分钟编号。一段占用或封控写成半开区间，包含起始分钟，不包含结束分钟，并且起始分钟早于结束分钟。

码头账本 `WharfLedger.plan` 与潮汐模块 `tidebook.span` 使用同一套分钟折叠和挖除。潮汐模块不带巷道。账本多出来的只有巷道维度，分钟本身不再另作一套。

同一条巷道里，两段占用之间如果没有空闲分钟，就折成一段对外值班。空闲分钟指落在前一段结束之后、后一段开始之前的分钟。折完以后，开始分钟取更早的，结束分钟取更晚的。被包住的段不再单独留下。折合要做完，结果里不能还剩两段可以继续折。不同巷道即使分钟相连，也各自保留。

巷道编号先去掉首尾空白，再按大写字母比较和输出。`a-1` 和 ` A-1 ` 是同一条巷道，输出写成 `A-1`。

封控不带巷道，作用到每一条出现过的巷道上。封控自己先按同一套分钟规则折成并集，再从占用里挖。只挖双方都包含的分钟。仅在端点相接时，没有共同分钟，占用不动。从中间挖开时，留下的左段到封控开始为止，右段从封控结束起继续。

输出按开始分钟升序，开始分钟相同再按规范化巷道编号升序。空的合法占用得到空列表。要先检查全部占用和全部封控，任何一段不合法就抛出 `ValueError`，不返回半份结果。成功或失败都不改调用方传入的列表，也不改里面的元组。

配载顺序里的洗舱间隔只用于 `wharfbook.cargo` 的货类衔接，不插入占用归并。占用归并不额外加分钟。

夜班重排会把整月预约一次交给 `plan`。北港一个月最多八万段占用。调度台在 1 秒内拿不到结果就中断这次重排。
